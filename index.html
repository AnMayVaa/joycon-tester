Joy-Con & Phone Tester

Controllers over Bluetooth (WebHID) · phone sensors via web APIs

WebHID isn't available in this browser

Full testing (gyro, accelerometer, rumble, lights) needs Chrome or Edge on desktop (Windows, macOS, Linux, ChromeOS), opened as a local file or over HTTPS. Basic button/stick testing via the Gamepad API is still available below.

How to connect

  1. Hold the small round sync button on the Joy-Con rail until the green lights run back and forth.
  2. Pair it in your computer's Bluetooth settings — it appears as Joy-Con (L) or Joy-Con (R).
  3. Click Connect Joy-Con above and pick it. Repeat for the other one — both get their own panel.

Tip: lay the Joy-Con flat on a table for the first second after connecting so the gyro can auto-calibrate. On Linux, the hid-nintendo driver may need udev rules for browser access.
